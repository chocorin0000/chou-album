# 超！アルバム Web 版

iPhone・iPad で使える「超！アルバム」です（Android 版と同じデータの形）。

- 開く: https://chocorin0000.github.io/chou-album/
- Safari で開いて、共有ボタン →「ホーム画面に追加」すると、アプリのように画面いっぱいで使えます。
- アルバムは iPhone・iPad の中（ブラウザの保存場所）に入ります。「保存・バックアップ」で zip に書き出したり、Google ドライブ（Google Apps Script、`Code.gs.txt`）へ自動で保存したりできます。
- Android 版で書き出した zip も読み込めます。同じスクリプトの URL と合言葉を入れれば、Android 版と同じフォルダに保存されます。

`tools/make_icons.py` はアイコンを作るスクリプトです（Android 版の `tools/make_icon.py` を使います）。
